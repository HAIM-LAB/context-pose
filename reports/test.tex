\tabledesc{Each row is a ContextPose model (context-queried temporal attention over the pre-event, event and post-event windows, with an optional gated face stream) given the ticked input streams, used alone, in pairs, in threes and all together.
\emph{Streams:}
\begin{itemize}
  \item P: upper-body pose (11 joints with $x$, $y$, confidence and real-time speed).
  \item A: the four binary event indicators coded by annotators.
  \item V: a 384-d MiniLM embedding of Qwen3-Omni scene descriptions, used as the context vector in place of or alongside A.
  \item F: frozen FER ViT face embeddings, kept only on steps that pass a frontal, YuNet-detector and brightness quality gate.
\end{itemize}
\emph{Offsets:} rows with A start from the event-annotation lookup's log-odds and learn a correction to it. Rows without A start from a constant offset fitted on the training folds, so no annotation information reaches them.
\emph{Protocol:}
\begin{itemize}
  \item Data: 153 development clips from 68 videos.
  \item Folds: video-grouped 5-fold cross-validation with duplicate videos merged; each clip is scored by a model trained on three folds and early-stopped on the fourth.
  \item Training: votes objective (binary cross-entropy on annotator vote shares), identical settings for every row (width 64, dropout 0.3, weight decay 0.05, learning rate $3\times10^{-4}$, pose augmentation, up to 60 epochs with patience 10).
\end{itemize}
\emph{Targets:} annotator-majority calls with ties excluded:
\begin{itemize}
  \item valence positive vs not positive (150 clips, 100 positive);
  \item arousal high vs low (148 clips, 33 high).
\end{itemize}
\emph{Metrics:}
\begin{itemize}
  \item Results are 5-seed ensembles: the majority of the seeds' calls, and the mean seed score for AUC.
  \item Balanced accuracy is the mean per-class recall (chance 50\%), with 95\% participant-bootstrap intervals in brackets.
  \item Decision thresholds are set on each model's own training clips, never on the scored fold.
\end{itemize}
\emph{References:} the top rows score each annotator against the other two, always predicting the majority class, and the non-learned lookup (training-fold mean vote share per indicator combination). Bold marks the best model in each column.
\emph{Findings:}
\begin{itemize}
  \item Valence signal comes from the face, and arousal signal from the context (annotation or VLM).
  \item VLM + face roughly matches annotation + face without the manual event labels.
  \item Adding pose never improves a combination: the full model (pose + annotation + face) is below annotation + face on both targets.
  \item No gain over the lookup excludes zero.
\end{itemize}}
\end{table}

\tabledesc{The networks regress the confidence-weighted consensus valence and arousal labels (on a $[-1, 1]$ scale).
\emph{Protocol:}
\begin{itemize}
  \item 153 development clips with video-grouped 5-fold cross-validation, on the original folds (before the duplicate-video merge).
  \item Predictions are averaged over 5 seeds.
\end{itemize}
\emph{Models:}
\begin{itemize}
  \item \code{text\_attention}: ContextPose conditioned on the CLIP ViT-L/14 embedding of the event sentence.
  \item \code{annotation\_attention}: the same model conditioned on the four binary event indicators.
  \item \code{annotation\_film}: the indicators modulate the pose features through FiLM.
  \item Pose only: the context input is zeroed.
\end{itemize}
\emph{Training:}
\begin{itemize}
  \item Default: width 128, learning rate $10^{-3}$, 30 epochs, patience 5.
  \item Regularised: width 64, dropout 0.3, weight decay 0.05, learning rate $3\times10^{-4}$, pose augmentation.
\end{itemize}
\emph{References:} the overall median and the context lookup (median label per indicator combination, fitted on the training folds) are non-learned.
\emph{Metrics:} MAE is the mean absolute error (lower is better) and CCC the concordance correlation coefficient (higher is better; 0 for a constant prediction). Mean MAE averages valence (V) and arousal (A).
\emph{Findings:}
\begin{itemize}
  \item No network beats the lookup, which is in bold as the best row.
  \item CLIP text and the indicators perform alike, because the event sentences are generated from the indicators.
  \item FiLM does not help.
  \item Regularisation lowers every network's mean MAE by about 0.015, mostly by pulling predictions toward a constant.
  \item Pose-only models match the full models, so pose adds no measurable signal.
\end{itemize}}
\end{table}

\tabledesc{The protocol and targets are those of Table~\ref{tab:spec}: regression of the consensus labels on 153 development clips, video-grouped 5-fold cross-validation on the original folds, predictions averaged over 5 seeds.
\emph{Configurations:}
\begin{itemize}
  \item Residual: the network predicts a correction to the training folds' lookup median instead of the label itself.
  \item Speed: a fourth pose feature with each joint's speed in shoulder widths per second at 25\,fps. Without it, frame-to-frame change stops reflecting real speed once each window (5 to over 30\,s long) is resampled to 32 steps.
  \item L1 / MSE: the training loss.
  \item Regularisation: as in Table~\ref{tab:spec}.
  \item S5: S4 with the context removed from the network; the residual still supplies the lookup.
\end{itemize}
\emph{Metrics:} MAE (lower is better) and CCC (higher is better) for valence (V) and arousal (A). Gain is the lookup's mean MAE minus the model's (positive means better than the lookup), with a 95\% participant-bootstrap interval where computed.
\emph{Findings:}
\begin{itemize}
  \item The speed channel was the first input through which the networks used pose: it lifted arousal CCC from about 0 to 0.17, and to 0.25 with the residual.
  \item That gain never became a lower MAE: every network ties or loses to the lookup (bold), and every interval includes zero.
  \item L1 loss closed only a little of the gap.
\end{itemize}}
\end{table}
